# Five-Minute Week 1 Walkthrough

1. **Problem and user (45 seconds):** operations administrators need a consistent record of maintenance issues across locations.
2. **Scope (45 seconds):** maintenance-request CRUD only; authentication comes in Week 2.
3. **Data model (60 seconds):** facilities, assets, maintenance requests, work assignments; explain asset/facility integrity.
4. **API demo (90 seconds):** health, list, read, create, update, invalid input, not-found.
5. **Safety and next steps (60 seconds):** fictional data, no secrets, add auth and authorization in Week 2, tests and deployment readiness in Week 3.
